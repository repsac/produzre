# Genre Examples

This directory contains **31 genre directories** with complete song examples organized by musical style. Each genre includes multiple complexity levels, making it easy to learn Produzre progressively or find a starting point for your own compositions.

## Example Complexity Levels

Most genres include three example tiers:

- **Simple** (`*-simple.yaml`) -- Minimal configuration, 1-2 sections, basic parameters (~20-30 lines). Ideal for understanding the core feel of a genre.
- **Full** (`*-full.yaml` or named variant) -- Multi-section arrangement with moderate-to-advanced parameters (~50-150 lines). Demonstrates verse/chorus/bridge structures, dynamic variation, and genre-specific techniques.
- **Recipe Showcase** (`*-recipe-showcase.yaml`) -- Demonstrates the recipe system with `genre:` tags, letting the engine auto-select genre-appropriate parameters for each instrument.

The five "original" genres (blues, rock, funk, jazz, metal) have four files each with uniquely named intermediate and advanced examples. All other genres follow the simple/full/recipe-showcase pattern.

## Learning Path

### Beginners

Start with **simple** examples to learn:
- Basic song structure (one or two sections, repeated)
- Minimal parameter configuration
- Core genre characteristics
- How `genre:` triggers recipe auto-selection

Recommended starting points: `rock/rock-simple.yaml`, `blues/blues-simple.yaml`, `pop/pop-simple.yaml`.

### Intermediate

Progress to **full** examples (or the named intermediate files in blues/rock/funk/jazz/metal) to explore:
- Multi-section arrangements (verse, chorus, bridge, solo)
- Dynamic variation through `intensity` per section
- Fill placement and section transitions
- Genre-specific techniques (shuffle, swing, syncopation, palm muting)

### Advanced

Master the **recipe-showcase** examples to understand:
- The recipe system and how `genre:` auto-selects instrument parameters
- Persona usage for instrument character
- How recipes, personas, and manual params merge together
- Cross-genre blending (see `mashup/genre-mashup.yaml`)

## Building Examples

```bash
# Build a single example
python3 -m produzre.cli build examples/genres/blues/blues-simple.yaml

# Build all examples in a genre directory
for f in examples/genres/reggae/*.yaml; do
  python3 -m produzre.cli build "$f"
done

# Build every genre example (all 31 directories)
for dir in examples/genres/*/; do
  for f in "$dir"*.yaml; do
    python3 -m produzre.cli build "$f"
  done
done
```

## Customization Tips

All genre examples are designed to be easily modified:

1. **Change Key** -- Modify `song.key` to transpose the entire piece.
2. **Change Tempo** -- Adjust `song.bpm` for faster or slower renderings.
3. **Extend Length** -- Add more repetitions or new sections in `arrangement`.
4. **Adjust Intensity** -- Modify `intensity` values per section to shape dynamics.
5. **Change Seed** -- Try different `song.seed` values for variation on the same structure.
6. **Override Recipes** -- Add manual parameters under any instrument to override recipe defaults.
7. **Swap Genre** -- Change the `genre:` tag to hear the same structure with a different genre's recipe set.

## Genre Characteristics

### Rock Family
- Power chords and tight voicings, driving backbeat drums
- Verse-chorus-bridge structures with clear dynamic arcs
- Subgenres range from soft rock (~95 BPM) to punk (~180 BPM)
- Alt-rock and grunge feature quiet-loud dynamics; prog-rock explores odd meters

### Metal Family
- Palm-muted power chords with high density and large interval leaps
- Double-kick drum patterns, blast beats in extreme sections
- Bass often locked to kick drum rhythm
- Breakdowns with half-time feel for impact

### Blues / Soul / R&B
- 12-bar and extended blues forms, shuffle and swing feels
- Walking bass patterns with chromatic approach notes
- Soul and R&B emphasize smooth pocket grooves at slower tempos (85-95 BPM)
- Gospel builds from soft to ecstatic with layered intensity

### Jazz / Funk
- Jazz: ii-V-I progressions, AABA forms, walking bass, swing feel (140-160 BPM)
- Funk: tight syncopated rhythms, slap bass, ghost notes on drums
- Both genres rely heavily on rhythmic sophistication over harmonic complexity

### Pop / Electronic
- Pop: clean structure, hook-oriented, moderate tempos (115-125 BPM)
- Electronic and techno: four-on-the-floor kicks, builds and drops (128-138 BPM)
- Dance-pop bridges the two with pop structure over electronic production
- New wave: synth-forward textures with post-punk energy

### World / Folk / Classical
- Folk and country: acoustic-driven, low syncopation, high on-beat emphasis
- Latin: clave-based rhythmic patterns, moderate tempos
- Reggae: offbeat skank, one-drop drums, highest syncopation of all genres (0.57)
- Ska: uptempo offbeat chops (155-160 BPM)
- Classical: sparse arrangements, lowest density, highest rest rates
